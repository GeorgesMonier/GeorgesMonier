

##  Georges Monier
Software Developer especializado en backend y arquitectura de aplicaciones web escalables, con experiencia full‑stack cuando el proyecto lo requiere. Trabajo con Python, SQL, PostgreSQL, Docker, Node.js, React, Angular y Springboot, aplicando buenas prácticas para construir software limpio, seguro, optimizado y fácil de mantener.

Me apasiona la integración de IA, la seguridad aplicada y la optimización del rendimiento, buscando siempre mejorar la calidad del código, automatizar procesos y crear sistemas robustos que aporten valor real.
